# BrewLab - Interactive Coffee Brewing Guide

A modern, interactive website for making perfect coffee at home. Built with vanilla HTML, CSS, and JavaScript.

## Features
- **Live Ratio Calculator**: Adjust cups + strength to get exact coffee/water grams
- **3 Brew Methods**: French Press, Pour Over V60, AeroPress with clickable steps
- **Brew Timer**: Preset timers for each method with alerts
- **Animated Hero**: CSS coffee cup animation
- **Fully Responsive**: Works on mobile and desktop
- **No Dependencies**: Pure HTML/CSS/JS

## Files
- `index.html` - Main page structure
- `style.css` - Modern styling + animations
- `script.js` - Calculator, tabs, and timer logic

## Deploy to GitHub Pages
1. Create a new repository on GitHub
2. Upload all 4 files: `index.html`, `style.css`, `script.js`, `README.md`
3. Settings → Pages → Source: `main` branch, `/root` folder
4. Your site goes live at `https://username.github.io/repo-name/`

## Customizing
- Change colors in `style.css` under `:root` variables
- Add more brew methods by copying the tab/content structure in `index.html`
- Tweak ratios in `script.js` `updateCalc()` function

Enjoy! ☕
